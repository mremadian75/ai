# Command Room UI Spec

## Layout

```text
Left rail: workspace, recent runs, playbooks, sources, reports
Center: command/playbook canvas and current run state
Right drawer: evidence, lineage, object inspector
Bottom rail: run timeline and usage strip
```

## Required areas

- Page title and product context.
- Playbook cards.
- Current run summary.
- Next recommended action.
- Review queue entry points.
- Usage/credit strip.
- Evidence drawer.
- Timeline drawer.
- Decision Map preview.
- Empty states.
- Error/success notices.

## Product language

Use: Signal Room, Command Room, Source, Run, Evidence, Insight, Brief, Draft, Memory, Usage, Outcome, Pattern, Decision Map.

Avoid: scraper control panel, generic dashboard, blank chat, raw developer debug console.
