# v0.3.52 — Sidebar navigation and focused results layout

## What changed
- Added a persistent Deep Trend Finder run sidebar to keep source execution, evidence and report sections navigable.
- Moved the full output area into the main workspace grid so results stay aligned with the sidebar instead of appearing as a detached wide block.
- Added dynamic sidebar run KPIs: provider rows, normalized rows, relevant rows and running sources.
- Duplicated primary run actions in the sidebar after run creation: Load report and Show evidence.
- Added section anchors for Brief, Sources, Evidence, Report and Full output.
- Added responsive fallback so the sidebar becomes a normal stacked panel on tablet/mobile.

## Why
The previous layout made long reports feel scattered. The sidebar now behaves like a control panel and navigation layer for long evidence/report sessions.
