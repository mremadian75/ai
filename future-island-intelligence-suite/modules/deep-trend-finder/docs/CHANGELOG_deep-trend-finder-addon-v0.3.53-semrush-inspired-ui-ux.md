# Deep Trend Finder Add-on v0.3.53 — Semrush-inspired UI/UX polish

Focused UI/UX patch. No database schema, shortcode, provider logic, or evidence scoring logic was changed.

## What changed

- Reframed the right sidebar into a left control panel / tool rail on desktop.
- Added a Semrush-inspired SaaS dashboard visual system: white cards, compact metrics, orange primary action, blue secondary/action links, softer gray app background, tighter spacing.
- Made the report area wider and denser so synthesis does not feel scattered.
- Improved evidence card density with thumbnail + body layout, two-column evidence groups on desktop, and tighter text clamping.
- Reduced visual noise in source cards, sidebar blocks, chips, and form controls.
- Improved responsive behavior: the rail collapses above the content on smaller screens.

## Design boundary

This is inspired by enterprise marketing-intelligence dashboard patterns used by tools like Semrush, not a visual copy of Semrush branding. Future Island identity remains intact.
